# Умные шахматы

Шахматы в браузере: игра со Stockfish (10, asm.js) или с другом по сети (PeerJS, WebRTC напрямую между браузерами).
Щиты защиты с итогом размена, полоска потенциала фигур, карта полей для выбранной фигуры.
Урок с наставником «Защита от детского мата»: 8 вариантов (за чёрных и за белых), каждый по 3 повтора, потом экзамен вперемешку.

Сайт — один файл `index.html` плюс `stockfish.js` и `peerjs.min.js`. Сборки нет.
